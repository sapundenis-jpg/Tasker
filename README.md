# FocusFlow PWA v0.4

Локальный веб-планировщик в стиле ретро-техники.

## Что нового в v0.4

- Ассистент-планировщик: показывает перегруз недели, просроченные задачи, тяжёлые дни и даёт совет.
- Кнопка «Разгрузить»: переносит гибкие, не критичные задачи в более свободные окна.
- Кнопка «Щадящий день»: убирает часть тяжёлых задач с сегодняшнего дня.
- Экспорт расписания в `.ics` для календаря.
- Push-ready слой: service worker умеет принимать push, в архиве есть пример маленького Node-сервера.
- Инструкция по установке на iPhone внутри приложения.

## Запуск локально

```bash
cd focusflow-pwa-v0.4
python -m http.server 8000
```

Открыть:

```text
http://localhost:8000
```

## Установка на iPhone без App Store

1. Опубликуйте папку `focusflow-pwa-v0.4` на HTTPS: Netlify, GitHub Pages, Cloudflare Pages или свой домен.
2. Откройте ссылку на iPhone в Safari.
3. Нажмите «Поделиться».
4. Выберите «На экран “Домой”».
5. Назовите приложение FocusFlow и нажмите «Добавить».
6. Запускайте приложение с домашнего экрана.

## Фоновые уведомления

Локальные уведомления работают, когда приложение открыто. Для уведомлений, когда приложение закрыто, нужен Web Push:

1. Разверните `push-server-example` на сервере с HTTPS.
2. Сгенерируйте VAPID-ключи:

```bash
cd push-server-example
npm install
npm run keys
```

3. Скопируйте ключи в `.env`.
4. Запустите сервер:

```bash
npm start
```

5. В FocusFlow нажмите «Push-готовность → Подключить» и вставьте URL сервера.

## Примеры фраз для парсера

- `завтра в 15:30 созвон с клиентом на час`
- `до пятницы подготовить презентацию на 2 часа`
- `в субботу утром придумать концепцию клипа`
- `после обеда ответить клиенту 30 минут`
- `первая половина дня монтаж на 2 с половиной часа`
- `не ставь сложное вечером, я устал`
- `разбей на 3 дня подготовку выступления на 6 часов`

## Важно

Данные хранятся локально в браузере. Для переноса между устройствами используйте экспорт/импорт JSON или экспорт `.ics` для календаря.
